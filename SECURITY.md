# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it through [GitHub private vulnerability reporting](https://github.com/x429d/mangla/security/advisories/new).

Include the macOS version, the affected version or commit, reproduction steps, and any relevant logs. Remove personal folder names and paths. Maintainers will acknowledge the report and coordinate a fix and disclosure.
